{%- comment -%} Client-side redirect for the 404 page (included first in on /404.html). GitHub Pages cannot issue server-side 301s, so this script recovers readers who follow old or near-miss addresses: /cacao/, /Agave, /black_eyed_peas/, /assets/posts/pecan/pecan.pdf, /admin/storykit-map-viewer, /Q11756 and so on. Limits: crawlers still receive a 404 status for these URLs, and search engines may or may not run the script. That is acceptable because the sitemap carries the canonical URLs; this is aimed at people following old links. It runs before the analytics include, so a recovered visit never records a 404 page view. Lookup order: 1. explicit aliases from site.data.redirects (keys already normalized) 2. generated table of every post, tab, admin page and standalone page 3. pattern rules (old static PDFs, renamed StoryKit guides, Wikidata IDs) Never redirects to the same path or to the home page as a fallback. {%- endcomment -%}
